# EverGrace Senior Care & Living Website

A modern, compassionate, fully mobile-responsive website and portal system for **Senior Care Services**, crafted specifically for seniors, adult children caregivers, and healthcare professionals.

---

## 🌟 Key Highlights & Specifications

- **Animated Preloader (1.5 Seconds)**: Every page includes an elegant medical preloader featuring a glowing heartbeat pulse, concentric ripple rings, brand typography, and an animated progress bar active for precisely 1.5 seconds before smoothly fading out.
- **Scroll Reveal & Micro-Animations**: Smooth hardware-accelerated intersection observer animations on section headers, cards, grids, images, and buttons with interactive hover transforms and pulsing emergency alerts.
- **Mobile First & Responsive from 320px (Zero Overlap)**: Thoroughly tested and hardened for 320px screens with zero horizontal overflow, fluid button wrapping, responsive navigation drawer, and collapsible dashboard headers.
- **Optimized WebP Images (<100 KB)**: All 34 images across every page are in genuine `.webp` format, compressed and verified to be strictly under 100 KB (averaging ~40 KB) for lightning-fast load times.
- **Senior & Caregiver Focused UI**: High-contrast, legible typography (`Plus Jakarta Sans`), soothing medical color palette (Teal `#0d7265`, Navy `#1a365d`, Warm Amber `#d97706`), accessible touch targets (≥ 44px), and clear call-to-actions.

## 🚀 How to Run & Preview

Open any `.html` file directly in any modern web browser:
```bash
# Launch Home Page directly
Start-Process "index.html"

# Or preview dashboards
Start-Process "dashboard-client.html"
Start-Process "dashboard-admin.html"
```
Or serve using any lightweight static server:
```bash
npx serve .
# or
python -m http.server 8000
```
